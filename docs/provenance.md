# Data provenance and reproducibility

## TCGA inputs

`data/sources.tsv` lists the selected TCGA LUAD/LUSC Xena expression,
methylation, copy-number, clinical, and methylation probe-map inputs.
`scripts/02_download.py` retrieves selected Xena datasets from
`https://tcga.xenahubs.net/download/` and records the actual successful URL
in `data/raw_manifest.tsv`, alongside the source ID, local filename, byte
count, UTC download time, and SHA-256 digest. The current raw manifest
contains nine Xena entries; GEO files are listed separately in
`results/validation/GSE37745/geo_sources.tsv`.

Without `--force`, Xena downloads are skipped when the manifest has an entry
and its named local file exists; use `--verify` to check those files against
the recorded digests. `--force` requests the selected Xena inputs again and
updates the manifest after each successful download.

Use `python scripts/02_download.py --verify` to compare downloaded files with
the saved digests. A changed checksum indicates that the local file does not
match the recorded download; it does not identify whether the source itself
has since changed.

Raw TCGA and GEO inputs are not committed. Retrieve Xena inputs with
`python scripts/02_download.py` and GEO validation inputs with
`python scripts/07_validate_geo.py --gse GSE37745`. The GEO series matrix
identifies platform GPL570; the script first tries its annotation file and
then a family SOFT file. Current saved metadata records the series-matrix URL
and the GPL570 annotation URL. Existing files in `data/raw/geo/` are reused
without a freshness check; the GEO source manifest records the file digest
but its `accessed_utc` date is written when the file is read, including on
reuse. The pipeline does not delete raw files.
Processed Parquet matrices are generated by `scripts/03_preprocess.py`; the
script also writes metadata, feature membership, small sample extracts, and
QC reports.

## External resources

Knowledge mining retrieves Reactome's current `ReactomePathways.gmt` through
`https://reactome.org/download/current/ReactomePathways.gmt.zip` (with a
`download.reactome.org` fallback), and the `MSigDB_Hallmark_2020` library
through Enrichr. It also uses HGNC REST aliases, PubMed E-utilities counts,
Open Targets GraphQL associations, and STRING network results. Open Targets
tries `EFO_0003060` and then `MONDO_0005233`; the saved report and cache
identify the returned disease as `MONDO_0005233 non-small cell lung
carcinoma`.

These resources are cached under `results/knowledge/cache/` without an
automatic expiry or refresh option. Reactome, Hallmark, Open Targets, and
STRING responses are reused from their JSON cache files; HGNC aliases and
PubMed counts use their own caches. Cached responses do not create new
provenance records. `knowledge_sources.tsv` is populated from requests made
during a run, not a complete inventory of cached resources: a run with some
fresh requests can replace it with only those requests, while a cache-only
run leaves an existing file in place. Therefore its dates and checksums are
not a reliable record of every resource version used by the current results.
No Reactome release identifier or retrieval date can be established from the
saved pathway cache/report; the URL selects the current release. Remote
resources can change, so identical inputs do not guarantee identical
annotations.

The access and licence entries in `data/sources.tsv` are leads, not legal
clearance. Before redistribution, manually review the applicable TCGA data
use terms, GEO record and source-paper terms, and each third-party resource's
current licence, attribution, and redistribution requirements. The code and
data may have different terms.

## Attribution, citation, and reuse

Use the following source acknowledgements in publications and when
redistributing derived results, as relevant to the specific result:

- **TCGA and UCSC Xena:** identify the TCGA cohorts and Xena datasets used,
  acknowledge both TCGA and the [UCSC Xena TCGA hub](https://tcga.xenahubs.net),
  and cite the relevant TCGA and Xena resource publications. The [GDC
  open-data policy](https://gdc.cancer.gov/access-data/data-access-policies)
  requires dataset/accession and repository acknowledgement and prohibits
  attempts to identify participants. This project obtains these matrices
  from Xena; check the applicable Xena and source-dataset terms before
  redistributing any source or participant-level data.
- **GEO:** identify GSE37745 and GPL570 and cite Botling et al. (2013),
  “Biomarker discovery in non-small cell lung cancer: integrating gene
  expression profiling, meta-analysis, and tissue microarray validation,”
  *Clinical Cancer Research* 19(1):194–204,
  [doi:10.1158/1078-0432.CCR-12-1139](https://doi.org/10.1158/1078-0432.CCR-12-1139).
  See the [GEO series record](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE37745)
  and [GEO terms](https://www.ncbi.nlm.nih.gov/geo/info/terms.html).
  Public availability of the series matrix or platform annotation is not
  treated here as a redistribution license; verify GEO, paper, and platform
  terms before republishing those source files.
- **Reactome:** acknowledge and cite Reactome when using its pathway data.
  Reactome's [published license](https://reactome.org/license) identifies
  database data and data-derived files as CC0; illustrations, branding, and
  other content may have different terms. The analysis uses the GMT pathway
  data, and no historical release is recorded in the saved cache.
- **MSigDB Hallmark 2020 and Enrichr:** acknowledge both the MSigDB Hallmark
  collection and [Enrichr's library service](https://maayanlab.cloud/Enrichr/).
  Follow [MSigDB's citation guidance](https://www.gsea-msigdb.org/gsea/msigdb/)
  (including the relevant gene-set sources). The license/redistribution terms
  applicable to this specific Hallmark 2020 library as served by Enrichr have
  not been verified; confirm them before redistributing gene-set contents.
- **Open Targets Platform:** acknowledge and cite the Platform; use its
  [current citation guidance](https://platform-docs.opentargets.org/citation).
  Open Targets states in its [license documentation](https://platform-docs.opentargets.org/licence)
  that Platform data are CC0 1.0, while underlying source-data terms may
  still apply.
- **STRING:** cite and acknowledge [STRING](https://string-db.org/) using the
  publication and attribution instructions applicable to the service/data
  version used. The exact API/data license and the version represented by the
  saved network outputs have not been verified.
- **HGNC:** acknowledge [HGNC](https://www.genenames.org/) and, where useful,
  cite *Genenames.org: the HGNC resources in 2023* (RRID:SCR_002827). HGNC's
  [license page](https://www.genenames.org/about/license/) states that its
  data are CC0 and recommends attribution.
- **PubMed / NCBI E-utilities:** acknowledge [NCBI PubMed/E-utilities](https://www.ncbi.nlm.nih.gov/books/NBK25501/)
  and describe the search/count queries where relevant. The pipeline stores
  derived query counts, not article text; do not assume that articles returned
  by PubMed share one license.

The verified license statements above are limited to the named providers'
published terms and the specific resource types described. TCGA/Xena source
redistribution, GEO/GPL570 and source-paper terms, MSigDB Hallmark 2020 via
Enrichr, and STRING API/data terms still require manual confirmation.
Aggregate reports, tables, and figures are shared subject to the applicable
terms for source datasets and resources; aggregation does not itself confer
redistribution rights. This documentation is not legal clearance. The
repository's root `LICENSE` file applies the MIT License to this project's
code and documentation, not to third-party datasets or external resources;
their applicable terms must be reviewed separately.

## Environment and execution

The supported environment is Python 3.11, with minimum runtime dependencies
listed in `requirements.txt` and a matching conda definition in
`environment.yml`. From the repository root:

```powershell
conda env create -f environment.yml
conda activate nsclc-mo
make all
make verify
```

The pipeline uses fixed random seeds for QC permutations, MOFA model runs,
cross-validation splits, and label permutations. MOFA+ defaults to seeds
1, 2, and 3; stage modeling defaults to 10 repeats and 200 label
permutations. These settings can be changed through the existing script
options and should be reported when results are regenerated.

Run scripts in numbered order. Re-running a step overwrites its generated
outputs. Do not run a step before its inputs exist. `--reuse` in the
preprocessing step reuses selected processed layers, but cohort definition
still requires the raw clinical and omics input headers.

## Git exclusions

`.gitignore` excludes local environments, raw downloads, regenerated
processed Parquet matrices, API caches, temporary downloads, and common
editor/runtime files. It does not remove files already present in the
workspace. The raw datasets and full Parquet matrices remain on disk and can
be rebuilt from the source manifests and pipeline.
